Cara Kerja Auto-Fallback Multi-API:

Sistem selalu menggunakan API Key dengan Prioritas #1 sebagai jalur utama. Saat kuota API Key #1 habis (HTTP 429 atau limit kuota bulanan tercapai), pipeline secara otomatis beralih (*switch*) ke API Key #2 (Cadangan) secara instan tanpa menghentikan proses scraping. Anda dapat mendaftarkan 2 atau lebih akun SerpApi untuk memperbesar kapasitas pencarian.
